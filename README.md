# Stations-of-the-Second-Order-daily-tables
Data and code from Brotchie et al. (in prep.) Digitising historical climate data using the Google Gemini Large Language Model

The data are available in Station Exchange Format as TSV files and in CSV files that imitate the original tabular structure.
The Station Exchange Format documentation is available at https://datarescue.climate.copernicus.eu/station-exchange-format-sef
The filename convention of the Station Exchange Format is STATIONNAME\_variablecode\_startdate\_enddate.tsv where the date format is YYYYMMDD. The variable codes are provided below.

Variable long name : SEF variable code
Air pressure at station level : p
Air pressure at mean sea level : mslp
Air temperature : Ta
Minimum temperature : Tn
Maximum temperature : Tx
Depression of wet-bulb temperature : dep\_wet
Vapour pressure : e
Relative humidity : rh
Wind direction : dd
Wind speed : w
Cloud cover : n 
Sunshine duration : ss
Minimum temperature on grass : TGn


For the CSV files from the composite dataset, the filename convention is SSO_stationname_YYYY_MM_COMPOSITE.csv where SSO is 'Stations of the Second Order'.
